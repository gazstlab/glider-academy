## Context

CPython on WebAssembly, in a worker, so that a learner's infinite loop does not
freeze the tab it is being taught in.

The trap in this spec is not the worker. It is that **`public/pyodide/` is
gitignored and nothing generates it.** If the vendoring step is forgotten,
`pnpm build` succeeds, Vercel deploys, `smoke-headers.sh` passes — it only checks
headers — and the lab is dead in production with nothing red anywhere. That is
the same shape as the failures `docs/pipeline.md` is proud of disarming, one
layer further in, and the acceptance check that closes it is asserting the
runtime reaches ready **in the built preview**, not in dev.

Pyodide is loaded from same-origin `public/pyodide/` rather than a CDN, because
COEP requires CORP on every cross-origin resource and `vercel.json` already
serves the CORP header for that path.

## Do

1. `scripts/vendor-pyodide.mjs` copies the pinned
   `node_modules/pyodide/{pyodide.mjs,pyodide.asm.js,pyodide.asm.wasm,python_stdlib.zip,pyodide-lock.json}`
   into `public/pyodide/`. Wire it as `predev` and `prebuild` so it cannot be
   skipped. Fail loudly if a file is missing rather than copying what is there.
2. `protocol.ts`: `type ToWorker` and `type FromWorker`, discriminated unions
   with a request id. Every message is `structuredClone`-safe.
3. `worker.ts` boots Pyodide from `/pyodide/`, reports ready, and handles
   messages. No DOM access.
4. `client.ts` exports
   `createPythonRuntime(): { ready; parseDag(src); runTask(id); dispose() }`,
   with `parseDag` and `runTask` returning rejected promises until S17 and S18
   implement them — declared now so the shape is fixed, not stubbed silently.
5. `e2e/runtime.spec.ts` asserts the runtime reaches ready in the **built
   preview**, in both browsers, within a generous timeout.

## Delivers

### Artifacts
The file list above.

### Surface
`src/runtime/protocol.ts` exports `ToWorker`, `FromWorker`.
`src/runtime/client.ts` exports `createPythonRuntime()` and `type PythonRuntime`.

### Invariants
- Pyodide is always loaded same-origin from `/pyodide/`. Never a CDN
- `public/pyodide/` is regenerated by `prebuild`; a build cannot ship without it
- Worker messages are `structuredClone`-safe, so `DagDef` crosses intact
- The worker never touches the DOM

### Evidence
The runtime e2e against the built preview, both browsers, plus the vendor script
output.

### Debt
`parseDag` and `runTask` reject. S17 and S18 fill them.
