## Context

§9 says UI copy lives in `src/locales/<locale>/*.json` and never inline. Today
that is a review item, and a review item is caught after it is written. This spec
turns it into a build failure, which is the difference between a rule and a
habit.

Two decisions come with it. The loader **throws** on a missing key rather than
falling back — for the same reason `check-locales.sh` exists at all: a silent
fallback gives the learner a screen in two languages with nothing red anywhere,
and `CONTRIBUTING.md` §5 names that as the one failure mode a teaching product
cannot afford. And copy is split one file per copy-owning surface — `common`,
`states`, `grid`, `graph`, `log`, `lab`, `home`, `lesson-04` — because
`check-locales.sh` compares per file, extra files cost nothing, and without the
split eleven later specs all edit `lab.json`.

This spec also closes a hole in the gate itself. With only `pt-BR` present,
`check-locales.sh` sets `targets=0`, never opens a source file, and prints ok. A
malformed or empty `pt-BR/lab.json` ships green today.

## Do

1. `src/i18n/index.ts`: eager `import.meta.glob` over
   `src/locales/<locale>/*.json`; export `I18nProvider`, `useT()` and
   `SOURCE_LOCALE = 'pt-BR'`. `useT()` returns
   `(key: string, vars?: Record<string, string | number>) => string`, keyed
   `file.path.to.key`, interpolating `{name}`. **Throws** on a missing key.
2. Seed `common.json` with `footer.trademark`, copied character for character
   from `README.md` § Trademark. §11 sets that wording in the README precisely so
   a legal line is never edited as a design tweak — do not reword it, do not
   translate around it.
3. Enable `react/jsx-no-literals` in `eslint.config.js`, scoped to `src/ui/**`
   and `src/screens/**`. Not repository-wide: test files and config legitimately
   contain strings.
4. Tighten `check-locales.sh` so the source locale is validated unconditionally,
   before the target loop: every `pt-BR/*.json` parses as JSON and contains no
   empty-string value. Keep the existing `skipped · no src/locales yet` path and
   the exit codes. Add a line to the header comment explaining the hole being
   closed — every script in that directory carries one.

## Delivers

### Artifacts
The file list above.

### Surface
`src/i18n/index.ts` exports `I18nProvider`, `useT()`, `SOURCE_LOCALE`.

### Invariants
- A missing key throws. Never a silent fallback, never the key echoed back
- Airflow vocabulary is not translated in any locale: `task`, `DAG run`,
  `upstream`, `backfill`, `up_for_retry` stay as they are
- Every component from here on imports `useT()`. A literal in `src/ui/**` or
  `src/screens/**` fails `pnpm lint`

### Evidence
The unit tests, `pnpm lint` on a deliberate literal, and `check-locales.sh`
against a deliberately empty value.

### Debt
`en` does not exist and is not started. §9 is explicit that this is correct:
whatever you start, you finish.
